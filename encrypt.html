凭据加密器

把 GitHub Token 加密成一行密文，供点歌页使用

1 · 填入 Token 与口令

GitHub Token（fine-grained，只需本仓库的 Contents: Read and write）
加密口令（解密时要用同一个；口令越随机越好）

2 · 生成密文

密文（一行）

3 · 怎么用

  1. 把复制到的 tokenBlob 与 passphrase 两行粘进 config.js。
  2. 把 tokenBlob 填好后，点歌页就能直接提交；口令留空则每次打开点歌页需要手动输一次口令（存当前标签页）。
  3. 想核对密文有没有写错：本页「验证密文能解回 Token」，或命令行 node decrypt.mjs "密文" "口令"。
  4. Token 泄露了就先去 GitHub 吊销，再用本页重新生成一份密文替换掉。

⚠ 说明：点歌页是纯静态网页，既然它自己能解出 Token，那么拿到网页的人也就能解出来。 加密的实际作用是：避免 Token 明文出现在仓库里（GitHub 的密钥扫描会自动吊销明文 Token）、挡住随手翻源码的人。 要做到「谁也拿不到」，只能用服务端代提交（config.js 里的 submitMode: 'proxy'）。

本页的所有计算都在你自己的浏览器里完成，不会把 Token 发往任何服务器（断网也能用）。

算法：PBKDF2-SHA256（25 万次迭代）→ AES-256-GCM 密文格式：MAI1.<迭代次数>.<salt>.<iv>.<密文>
